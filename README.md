# Python AI, LLM & RAG Learning Repository

A hands-on learning repository focused on **Python programming, Artificial Intelligence, Large Language Models (LLMs), and Retrieval-Augmented Generation (RAG)**.

This repository contains practical Python exercises and experiments as I learn to build AI-powered applications, work with LLM APIs, process documents, generate embeddings, and retrieve relevant information using vector databases.

## 🚀 Project Overview

The repository is organized around learning Python and exploring AI/LLM development through practical examples.

### Key Areas

- **Python Programming** – Core Python concepts, functions, data structures, file handling, and reusable modules.
- **LLM Integration** – Working with Google's Gemini API to generate AI responses.
- **Document Processing** – Extracting text and information from PDF documents.
- **Text Chunking** – Splitting document content into smaller chunks for retrieval.
- **Embeddings** – Exploring semantic embeddings using Sentence Transformers.
- **Vector Database** – Storing and retrieving document content using ChromaDB.
- **RAG (Retrieval-Augmented Generation)** – Providing retrieved document context to an LLM to generate relevant answers.

## 🧠 RAG Project – PDF Question Answering

One of the main projects in this repository is a document-based question-answering system using RAG.

It allows users to ask questions about PDF documents and receive answers generated by Gemini using relevant content retrieved from ChromaDB.

### RAG Workflow

1. **Document Loading:** Read PDF files from the `Documents` directory.
2. **Text Extraction:** Extract text from PDF files using PyPDF.
3. **Text Chunking:** Divide extracted text into smaller, overlapping chunks.
4. **Vector Storage:** Store document chunks in a persistent ChromaDB collection.
5. **Semantic Retrieval:** Retrieve relevant chunks based on the user's question.
6. **LLM Generation:** Pass the retrieved context and question to Gemini.
7. **Response Streaming:** Display the generated response in the terminal.

### Technologies Used

|---|---|

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Santhosh2345/python-ai-llm-rag.git
```

### 2. Navigate to the Project

```bash
cd python-ai-llm-rag
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Gemini API Key

Create a Gemini API key and configure it as an environment variable.

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="your_api_key"
```

Keep your API key private. Never commit API keys or `.env` files to GitHub.

### 6. Add PDF Documents

Place your PDF files inside the `Documents` directory.

### 7. Ingest Documents into ChromaDB

Run the ingestion module from the project root:

```bash
python -m python.LLMLearn.RAG_Chromadb.ingest_documents
```

This extracts the PDF content, creates chunks, and stores them in the persistent ChromaDB collection.

### 8. Ask Questions

Run the question-answering module:

```bash
python -m python.LLMLearn.RAG_Chromadb.ask_questions
```

Enter your question in the terminal and type `exit` to stop the application.
